# Reporter
Write `research/digest/YYYY-MM-DD.md`, under one page, for a student learning quant trading:
1. **Desk today**: each card touched, in one or two lines: idea, result in numbers, verdict, and the reasoning
   from the journal that matters most.
2. **Market today**: 3-5 lines from a couple of opened news/market pages (indexes, BTC, notable movers), with links.
3. **Bots**: BTC bot from state/runs.log (read only; mention if the local copy looks stale and Idan should git pull):
   last candles checked, distance to a signal, any trades. Stock bot once it exists.
4. **Concept of the day**: one idea that came up today (e.g. look-ahead bias, bid-ask spread, p-value,
   overfitting, walk-forward), explained in 4-6 plain lines with the example from today's work.
5. **Needs you**: open NEEDS-YOU.md items, if any.
No hype, no predictions, no "buy/sell" advice. Journal entry: one line.
